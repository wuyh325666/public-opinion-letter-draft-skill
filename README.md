# 企业舆情函件撰写 Skill

根据舆情 Excel、已有核查结果及事实材料，按“一份表格、一份函件”撰写企业说明函、举报函或撤稿函，默认交付可编辑 Word。具体规则见 [SKILL.md](skills/public-opinion-letter-draft/SKILL.md)。

## 主要规则

- 使用企业发函口吻，按问题类型归纳具体行为、品牌关联、企业影响和处理诉求。
- 正文不包含账号、链接、记录编号、台账或核查过程，也不默认附链接清单。
- 基于已有核查表写函时，从未删除、仍可访问的内容中提取有事实依据的问题；不把无法访问标签当作侵权证明。
- 不自动发信、提交举报、执行撤稿或复制印章。
- 客户确认的品牌固定段落单独保存在使用者本机，按相应客户授权使用。

## 使用方式

将 `skills/public-opinion-letter-draft` 文件夹放入使用者的 Skill 目录。提供需要处理的表格、发函主体、收件方以及可用事实材料，然后提出：

> 使用 public-opinion-letter-draft，根据这份核查表和事实材料撰写一封综合说明函。一表一函，正文不要链接、账号和台账。

如果需要重新核查链接，应另行使用 `public-opinion-link-check`；本仓库不包含链接巡查 Skill。生成 Word 时，可配合环境中的 documents Skill。

## 客户固定文案

本仓库仅保存通用规则和虚构示例，不含李宁等客户的实际固定模板。需要使用客户固定文案时，由使用者在本次任务中提供已确认的版本，或按照 Skill 的规定在自己本机配置对应品牌模板。缺少模板时不得声称已经应用客户固定文案。
