# 依据使用规则

正式引用前核对官方原文的名称、发布机关、日期、现行状态、具体条文和适用对象。内部核对记录留在当前任务工作区，不随函默认输出。

- 《民法典》中名誉权相关规定：从官方现行原文核对条号及适用主体，不把图片中的引文默认当作准确条文。名誉权规定不自动证明当前行为已经构成侵权。
- 涉企侵权信息治理通知：按具体行为匹配侮辱贬损、虚假误导、失真旧闻关联等实际条目，避免把一般负面评价解释为一概禁止。
- 《整治涉企侵权信息 优化营商网络环境自律公约》：区分行业自律要求与法律。逐字引述须核对原文；“禁止编造、传播涉企虚假信息”等旧函概括不得未经核对加引号冒充原文。
- “清朗”专项行动：写明实际匹配的行动名称及对象，不笼统声称所有负面舆情违反专项要求。AI治理依据须有AI相关事实，体育饭圈依据须与攻击对象、行为及适用范围相符。
- 专家解读、媒体评论、征求意见稿：不能当生效法律；内部研判不能写成部门已经作出认定。用户提供的个案判断要确认其适用对象及是否可对外引用。

正文以事实和企业诉求为主，依据通常用一段概述即可。法律结论、政策要求和企业请求分别表达。没有匹配依据时不堆砌法规；不能以公共政策补齐具体案件证据。
